# 🤖 Nova AI — Chatbot

A modern, responsive chatbot interface built with HTML, CSS, and JavaScript. Nova AI features an interactive chat experience, suggested prompts, and instant demo responses.

## 🌐 Live Demo

**[Launch Nova AI Chatbot](https://arhamkhancr608-rgb.github.io/ai-chatbot/)**

## ✨ Features

* 💬 Interactive chat interface
* 🎨 Modern dark-themed design
* 📱 Responsive layout for mobile and desktop
* ⚡ Instant demo responses
* 💡 Suggested prompts to start conversations
* 🕒 Message timestamps
* 🧹 Clear chat functionality
* ⌨️ Keyboard-friendly controls

## 🛠️ Built With

* **HTML5** — Page structure
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Chat interactions and demo response logic

## 🚀 Getting Started

1. Open the live demo using the link above.
2. Type a message in the input field.
3. Click the send arrow to receive a demo response.
4. Try the suggested prompts to explore the interface.
